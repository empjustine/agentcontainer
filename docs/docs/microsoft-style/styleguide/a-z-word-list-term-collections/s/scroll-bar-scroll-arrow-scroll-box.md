# scroll bar, scroll arrow, scroll box

Most of the time, avoid talking about elements in UI. Instead, describe what the customer needs to do.

Don't use _arrow_ to refer to a _scroll arrow_.

Don't use _slider_ or _slider box_ as a synonym for _scroll box_.

Don't use _gray_ or _shaded area_ to refer to the _scroll bar_.
