# start up, startup

Don't use _start up_ as a verb. Use _start_ instead.

**Note** Use _open,_ not _start,_ to describe selecting a program or app from the Start menu to open it.

Don't use _on startup_ or similar noun phrases in content for a general audience. It's OK to use _on startup_ in content for a technical audience.

It's OK to use _startup_ as an adjective in phrases such as _startup screen_.

**Examples**  
To open the app, select the icon.  
When the app opens, a startup screen appears.  
Open OneNote and start taking notes.
