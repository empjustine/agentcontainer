# stop, stop responding

Don't use _stop_ to mean _exit a program_. It's OK to use _stop_ for hardware operations.

Use _stop responding_ only when a program encounters a problem and can't close itself. Use _close_ to describe the action a program takes to close itself when it has encountered a problem and can't continue.
