# UPnP

Don't spell out as _Universal Plug and Play_. Don't use as a synonym for _Plug and Play_ or _PnP_.

Use _UPnP_ as an adjective followed by _certified,_ if appropriate, and a specific term, such as _device, architecture,_ or _standards._  
**Example**  
This UPnP certified device features ....

Don't use _UPnP_ to refer to an uncertified device.

Don't use as a noun by itself. For example, don't say, _UPnP is an architecture for pervasive peer-to-peer network connectivity._ Rephrase the sentence as, _The UPnP architecture enables pervasive peer-to-peer network connectivity._

For other guidelines, see the [Open Connectivity Foundation website](https://openconnectivity.org/).
