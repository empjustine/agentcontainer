# using, by using, with

In instructions or technical content, use _by using_ or _that use_ to eliminate ambiguity.

**Examples**  
Refine your pictures by using the photo editor.  
Azure DNS is a hosting service that uses Azure infrastructure to provide DNS name resolution.

Don't use _with_ as a synonym for _using_ or _by using._ It's OK to use _with_ in marketing contexts and with product and service names.

**Example**  
With OneDrive, you can share your favorite things across your favorite devices, including PCs, Macs, tablets, and phones.
