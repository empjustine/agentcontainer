# un-

In general, don’t hyphenate words beginning with _un-,_ such as _undo_ and _unread,_ unless it’s necessary to avoid confusion, as in _un-ionized,_ or unless _un-_ is followed by a proper noun, as in _un-American._ When in doubt, check [_The American Heritage Dictionary_](https://ahdictionary.com/).

To learn more about hyphenation, see [Hyphens](~/punctuation/dashes-hyphens/hyphens.md).
