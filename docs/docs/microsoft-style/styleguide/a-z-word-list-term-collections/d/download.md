# download

Use _download_ to describe the intentional transfer of data and files to a system or device. Use _install_ to describe adding apps, hardware, and drivers to a device.

When you use _download_ as a verb, describe what the customer is transferring _and_ where the customer is transferring it _to._ In
grammatical terms, use both a subject (the thing to be downloaded) and
an object (the thing the subject is downloaded to) with the verb _download._

Don't use _download_ to describe the process of opening, viewing, or switching to a webpage.

It's OK to use _download_ as a noun to describe data or a file that's available for downloading or that has been downloaded.

In your writing, make sure it's clear whether _download_ is used as a noun or verb.

**Examples**<br />Install the app.<br />To learn more about integrating data security across your enterprise, download the poster to your device.
