# document

Use for text files, such as files created in Word.

To refer to any editable file located in a folder, use a more specific word, such as _workbook, presentation,_ or _database,_ if you can. Precede the descriptive word with a product name, such as _PowerPoint presentation,_ when you need to distinguish a file created in a certain product from files created in other products.

Use _file_ for more general uses, such as _file management_ or _file structure,_ or references to files of mixed types.
