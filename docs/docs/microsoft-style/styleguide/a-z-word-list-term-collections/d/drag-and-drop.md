# drag, drag and drop

Don't use _drag and drop_ except as an adjective to describe behavior that a programmer puts in a program, such as _drag-and-drop editing_ or _drag-and-drop feature_. Use _move_ or _drag_ instead.

Don't use _click and drag._ It's OK to use _press and drag_ to teach mouse techniques in content that teaches beginning skills.
