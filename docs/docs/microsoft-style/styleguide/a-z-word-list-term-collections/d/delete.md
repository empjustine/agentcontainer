# delete

Use as a verb to describe the results of using the **Delete** or **Cut** command, such as moving files to the **Recycle Bin** in Windows, moving items to the Deleted folder in Outlook, and moving items to the clipboard. Use _delete_ to describe these actions even if the customer uses a different method, such as by dragging a file to the **Recycle Bin** or using the **Cut** command.

Use _delete_ to refer to actions that result from pressing the Delete or Backspace key on the computer, such as deleting selected text.

Don't use _delete_ as a synonym for _remove_. Don't use _cut_ or _erase_ as a synonym for _delete_.

**Examples**  
Delete the second paragraph.  
Delete MyFile.txt from the Windows folder.  
Remove the **Size** column from the Inbox.
