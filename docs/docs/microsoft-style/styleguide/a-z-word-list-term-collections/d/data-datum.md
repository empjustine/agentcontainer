# data, datum

Use _data_ as both a singular and plural noun. Don't use _datum._

Always use _data_ with a singular verb, even if you're talking about more than one data set. Don't use _the data are._

Lowercase _data_ unless it's at the beginning of a sentence or phrase.

**Examples**  
The data shows that 95 percent of users prefer a graphical interface.  
The data gathered so far is incomplete.  
These facts contradict earlier data.
