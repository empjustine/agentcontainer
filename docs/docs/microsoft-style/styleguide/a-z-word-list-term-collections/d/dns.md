# DNS

Spell out as _Domain Name System,_ not _Domain Name Server._ When discussing the DNS networking protocol, spell out _Domain Name System_ on the first mention. When discussing the Windows DNS feature, don't spell out _DNS._

The Windows feature is _DNS,_ not _DNS Server_ or _Microsoft DNS Server._ If you must emphasize that you're referring to the Windows feature and not to the networking protocol, mention Windows.

Don't use _dynamic DNS_ or _DDNS._

A DNS server (lowercase _s_) is a computer that's running DNS server software. DNS Server (capital _S_)
is the Windows service that appears in the Computer Management console.
In general, refer to the service only in a discussion about
stopping and starting it.

A DNS client (lowercase _c_) is a client of a DNS server. DNS Client (capital _C_)
is the Windows service that appears in the Computer Management console.
In general, refer to the service only in a discussion about stopping
and starting it.
