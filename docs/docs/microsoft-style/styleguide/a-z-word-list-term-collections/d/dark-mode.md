# dark mode

Lowercase, two words.
_Dark mode_ is a display setting that changes the interface from a bright background color to a darker color. This setting can be easier on the eyes in lower-light environments and for people who prefer interfaces that aren’t as bright.

**Examples**  
Use _dark mode_ to reduce eye strain.

Turn on _dark mode_ automatically at sunset.
