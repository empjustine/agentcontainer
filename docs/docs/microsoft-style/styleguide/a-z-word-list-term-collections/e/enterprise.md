# enterprise

It's OK to use _enterprise_ for an IT pro or developer audience to mean a _large company_ or _corporation_. Use as an adjective if possible, as in _enterprise computing_ or _enterprise deployment,_ rather than as a noun to mean _corporation_.

Don't use in content for a general audience.
