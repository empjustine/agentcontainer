# e-sports

Always hyphenate. Don't use _esports_ or _eSports._

Use _E-sports_ at the beginning of a sentence or heading. In uncommon situations where title-style capitalization
is required, use _E-Sports._

**See also** [Capitalization](~/capitalization.md)
