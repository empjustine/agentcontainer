# input/output, I/O, input/output control

Avoid _input/output_ in content for a general audience. If you must use it, spell out on the first mention, and then abbreviate as _I/O_.

In content for a technical audience, you don't need to spell out on the first mention.

Use _input/output control_ only in content for a technical audience. Always spell out on the first mention. On subsequent mentions, it's OK to abbreviate as _I/O control_ or _IOCTL_.
