# knowledge base, Knowledge Base

Use title-style capitalization to refer to the Microsoft Knowledge Base. (You don't need to precede _Knowledge Base_ with the company name.)

Otherwise, use lowercase for generic references to a _knowledge base,_ or _expert system_.
