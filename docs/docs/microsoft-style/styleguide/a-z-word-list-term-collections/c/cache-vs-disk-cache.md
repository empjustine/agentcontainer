# cache vs. disk cache

Differentiate between _cache_ and _disk cache_.

- Use _cache_ to refer to a special memory subsystem where data values are duplicated for quick access.
- Use _disk cache_ to refer to a portion of RAM that temporarily stores information read from a disk.

Don't use _cache_ or _file cache_ to refer to the location of internet files that are downloaded as you browse the web. Use _Temporary Internet Files folder_.
