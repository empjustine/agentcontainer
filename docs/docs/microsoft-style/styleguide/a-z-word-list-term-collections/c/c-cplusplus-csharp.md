# C, C++, C\#

It's OK to use _C, C++,_ and _C\#_ as adjectives. Don't form hyphenated modifiers with them, such as _C-based_ or _C-callable_.

**Examples**  
a C program  
a program based on C++  
built with exported functions that are callable by C
