# combo box

Two
words. Use only in content for a technical audience to describe a box
in which the user can enter or select a value. Don't use in content for a general audience. Instead, refer to it as a _box,_ using the label provided in the UI.

Use _enter_ to indicate that the user can either type an item in the box or select an item in the list. Or just say _For \[Control name\],_ _enter \[value\]._

**Examples**  
In the **Size** box, enter the font size you want.  
For **Size**, enter a font size.
