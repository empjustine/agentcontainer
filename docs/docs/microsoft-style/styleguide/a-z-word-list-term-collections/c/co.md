# co-

In general, don’t hyphenate words beginning with _co-,_ such as _coauthor_ and _coordinate,_ unless it’s necessary to avoid confusion. When in doubt, check [_The American Heritage Dictionary_](https://ahdictionary.com/).

To learn more about hyphenation, see [Hyphens](~/punctuation/dashes-hyphens/hyphens.md).
