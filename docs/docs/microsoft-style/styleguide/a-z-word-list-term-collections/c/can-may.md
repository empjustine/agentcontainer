# can, may

When you see _can_ in your writing, consider deleting it. _Can_ implies ability but not action. Rewrite to describe the action if possible.

**Example**  
Use the **/b** option to force a black-and-white screen.

When ability is what you need to express, it's OK to use _can_ to describe actions or tasks that the reader or program is able to do. Use _might_ to express possibility. Don't use _may,_ which might be interpreted as providing permission.

Don't substitute _could_ for _can_ unless you're referring to the past.
