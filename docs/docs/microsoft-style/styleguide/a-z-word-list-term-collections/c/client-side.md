# client side, client-side

Don't use for a general audience. Use _client_ instead.

It's OK to use _client side_ in writing for a technical audience when it refers specifically to the client part (side) of a program or protocol that acts on both a server computer and a client computer.

Avoid using _client-side_ as an adjective. If you must use it as an adjective, hyphenate it.
