# connect

Use _connect, make a connection,_ and similar phrases to describe attaching a computer to a network, whether intranet or internet.

Don't use _connect_ as a synonym for _sign in_ or _map,_ as in mapping a drive letter to a shared network folder. But use _disconnect_ to describe removing a mapped network drive.
