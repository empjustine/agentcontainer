# bottom left, bottom right

Don't use except in discussions of the **BottomLeft** and **BottomRight** properties. Use _lower left_ and _lower right_ instead.

Hyphenate _lower left_ and _lower right_ as adjectives.

**See also** [lower left, lower-left, lower right, lower-right](../l/lower-left-lower-right.md)
