# bi-

In general, don't hyphenate words beginning with _bi-,_ such as _bidirectional,_ _bimodal,_ and _bimonthly,_ unless it's necessary to avoid confusion. When in doubt, check [_The American Heritage Dictionary_](https://ahdictionary.com/).

To learn more about hyphenation, see [Hyphens](~/punctuation/dashes-hyphens/hyphens.md).
