# below

Don't use to mean _later_.

Don't use as an adjective preceding a noun (_the below section_) or following a noun (_the code below_). Use a hyperlink, or use _later_ or _the_ _following_.

**Examples**  
Use the following code to display information about the database.  
See [Installation instructions](https://example.com/).  
See Installation instructions, later in this article.
