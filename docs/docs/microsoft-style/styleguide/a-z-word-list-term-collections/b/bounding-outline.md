# bounding outline

Use to describe the visible element, usually a dotted rectangle, that surrounds a set of selected elements. If necessary, use _dotted rectangle_ or _dotted box_ to describe the bounding outline in content for a general audience, and then use _bounding outline_ in subsequent references.

Don't use _marquee_ as a synonym.
