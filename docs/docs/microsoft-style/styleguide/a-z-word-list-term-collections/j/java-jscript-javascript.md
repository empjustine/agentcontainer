# Java, JScript, JavaScript

Use _Java_ to refer to the object-oriented programming language developed by the Sun Corporation.

Use _JScript_ to refer to the Microsoft implementation of the ECMAScript scripting language specification, an open standard.

Use _JavaScript_ to refer to the widely used web-based programming language, under the Oracle trademark.
