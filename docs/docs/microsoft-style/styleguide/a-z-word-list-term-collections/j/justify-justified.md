# justify, justified

Don't use as a synonym for _aligned_. Justified text is text that is both left-aligned and right-aligned. To describe alignment on one margin only, use _left-aligned_ or _right-aligned,_ not _left-justified_ or _right-justified_.

If your content has an index or a glossary that includes articles about alignment, include _justify_ in the index or glossary with cross-references to _align, left align,_ and _right align,_ as appropriate.
