# voicemail

One word. Don't abbreviate as _v-mail_ or _vmail_.

Use to
refer generically to a voicemail app, to refer collectively to
messages, or to refer to an individual message. If necessary to
distinguish these meanings, use _voicemail message_ or _message_ to refer to an individual voicemail.

Don't use as a verb. Use _leave a voicemail_ or _leave a message_ instead.

**Examples**  
You have two new voicemails.  
To respond to the caller with a message ....
