# Windows, Windows-based

Use _Windows_ as a modifier for aspects or elements of the Windows operating system. Don't use _Windows-based._

It's OK to use _Windows user_ sparingly to avoid awkward constructions, but try to avoid _user_ in general.

**Examples**  
Windows app  
Windows device  
the Windows Recycle Bin  
a device running Windows
