# Wi-Fi

Try to use a general phrase instead, such as _wireless network,_ or refer to the specific technology that you're describing, such as _wireless LAN_.

_Wi-Fi_ is a proper noun and a registered trademark. Capitalize and hyphenate when referring specifically to Wi-Fi technologies. Don’t use _WiFi, wifi,_ or _Wifi_. Don’t include the registered trademark symbol (&reg;).
