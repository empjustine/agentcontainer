# work area, workspace

_Work area_ is two words. _Workspace_ is one word.

In general, don't discuss UI. Instead, talk about what the customer wants to do.

If it's necessary to describe UI, use _workspace_ to refer to the area within a window where the customer interacts with the UI.

Use _work area_ only when the term has a specific meaning in a particular product.
