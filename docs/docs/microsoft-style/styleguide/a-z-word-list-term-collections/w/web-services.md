# web services

Use _web services_ to refer to protocols and data formats, like XML, SOAP, and WSDL, that provide the means for integrating web-based apps.

Don’t use _web service_ or _web services_ to refer generally to apps and services that you access online. Instead, mention the service by name or use _service_ or _services_ instead.
