# message

Don't use _message_ as a verb. Use _send, receive, email, text,_ or _send an_ _IM_ instead.

Use _email,_ _message,_ or _email message_ to refer to an item sent or received using email.

Use _text_ or _text message_ to refer to an item sent or received using SMS.

To refer to an item sent or received using instant messaging, spell out _instant message_ on the first mention if your audience might not be familiar with the abbreviation. After that, it's OK to use _IM._
