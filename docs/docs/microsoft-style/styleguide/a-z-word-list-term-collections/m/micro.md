# micro-

In general, don't hyphenate words beginning with _micro-,_ such as _microprocessor_ and _microsecond,_ unless it's necessary to avoid confusion. When in doubt, check [_The American Heritage Dictionary_](https://ahdictionary.com/).

To learn more about hyphenation, see [Hyphens](~/punctuation/dashes-hyphens/hyphens.md).
