# Microsoft Software License Terms

When referring to the license agreement, use _Microsoft Software License Terms,_ not _End-User License Agreement_ or _EULA_. On the first mention, use the full name. On subsequent mentions, it's OK to shorten to _license terms_.

Don't use _licensing terms_.
