# multiple selection

Use to refer to a selection that includes multiple items. It's OK to use _adjacent selection_ if you must emphasize that the selected items are adjacent to one another.

Don't use _disjoint selection,_ _nonadjacent selection,_ or _noncontiguous selection,_
except in content for a technical audience, and only if the term
appears in the UI or API. If you need to refer to nonadjacent selected
items, use _multiple selection_ or list the specific items.
