# remote

It's OK to use _remote_ as an adjective to describe a person or computer at another site.

Don't use _remote drive_ to describe a drive on a remote computer. Use _network drive_ instead.

Don't use _remote_ as a verb.

Don't use _remote_ as a noun except to refer to a remote-control device.
