# root directory

In content for developers, use _root directory,_ not _home directory,_ to refer to the directory or folder from which all other directories or folders branch. In Windows, the root directory is indicated by a backslash (\\). Don’t shorten to _root_ when you mean the directory.

In other content, use _top-level folder_.

**Example**  
Change to the root directory, and enter the following command: **edit autoexec.bat**
