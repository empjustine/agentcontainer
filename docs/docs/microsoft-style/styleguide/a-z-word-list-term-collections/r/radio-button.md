# radio button

Use _radio button_ only in content for developers in which the API includes the term. In that case, use wording such as _\<name\> option button_ (also known as a _radio button_).

In other content, refer to a radio button by its label. If you must provide a descriptor, use _option_. Capitalize the label text as it appears in the UI, but don't capitalize the word _option_.
