# list box

Two words.

In general, avoid talking about UI. Instead, talk about what the customer needs to do.

When you need to help a customer interact with UI, refer to a list box by its label and the word _list,_ not _list box_. For the Mac, use _pop-up list_ to refer to unnamed list boxes.

**Examples**  
In the **Background** list, select **Coffee Bean**.  
In the pop-up list, select **Microsoft Excel**. (Mac only)
