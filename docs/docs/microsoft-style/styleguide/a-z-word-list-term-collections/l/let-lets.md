# let, lets

Don't use _lets_ (or _allows_ or _enables_) to refer to things that Microsoft or Microsoft apps make possible for the customer. Instead, focus on what the customer wants to do.

**Example**  
Present schedule information in a variety of ways using Microsoft Project.
