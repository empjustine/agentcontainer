# n

Use a lowercase _n_ in italic type to refer to a generic use of a number—when the value of a number is arbitrary or immaterial.

**Example**  
Move the cursor _n_ spaces to the right.

Reserve a lowercase _x_ in italic type for representing an unknown in mathematical equations (a variable).

**Global note** Because _n_ doesn't refer to the generic use of a number in all languages, using _n_ for this purpose might lead to mistranslation in machine-translated content.
