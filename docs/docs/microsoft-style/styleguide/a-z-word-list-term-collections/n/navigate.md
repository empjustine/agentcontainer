# navigate

Don't use to describe going from place to place on the internet or an intranet. Use _browse_ instead.

To describe going directly to a webpage or website, whether by entering a URL or selecting a hyperlink, use _go to_.

**Examples**  
To browse the web, select any link on your home page.  
To go to a webpage, enter the address of the page in the Address bar, and then select **Go**.

Avoid referring to UI controls and buttons as _navigation_ buttons and to webpages that orient the customer as _navigation_ topics or _navigation_ pages. Most of the time, use _buttons, topics,_ and _pages_ instead.

Don't use _navigation pane_ unless the term appears in the UI. Use _left pane_ instead if you can.
