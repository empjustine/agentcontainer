# preview

Prerelease versions of software and services are typically identified as _Product Name Preview_ (preferred) or _Code Name Preview._

In generic references, lowercase _preview._

Avoid using _beta_ to refer to a prerelease product that's ready for unstructured testing by customers. Use _preview_ instead.

**Examples**  
Office 2016 Preview  
Windows 10 Insider Preview  
Microsoft Power BI Preview  
A preview of Azure Container Service is available.
