# parenthesis, parentheses

Use _opening parenthesis_ or _closing parenthesis_ for an individual parenthesis, not _open parenthesis,_ _close parenthesis,_ _beginning parenthesis,_ _ending parenthesis,_ _left parenthesis,_ or _right parenthesis_. It's OK to use _parenthesis_ by itself if it doesn't matter or it's clear which parenthesis is being discussed.
