# frameset

Use only in content for developers.

Use _frames_ to refer to the independently scrollable regions on a webpage.

Use _frameset document_ to describe the HTML document that describes the frame layout in a frames page.

Use _frames page_ to describe the page itself, but don't use this term in content for a general audience. In general discussions, use _frames_.
