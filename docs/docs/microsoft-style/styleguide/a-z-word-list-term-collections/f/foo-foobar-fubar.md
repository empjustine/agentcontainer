# foo, foobar, fubar

Don't use _fubar_.

Don't use _foo,_ _foobar,_ or related words in content for a general audience. It's OK to use
these words as placeholders or variable names in content for a
technical audience, but if you can, use another placeholder instead,
such as _Example.exe_.
