# y-axis

Lowercase. Hyphenate.

On the first mention, refer to the y-axis as the _value (y) axis_. On subsequent mentions, use _y-axis_. It's OK to use _vertical (y) axis_ in content for a general audience.

Don't use italic formatting for the _y_ in _y-axis_ unless the entire word is italic.
