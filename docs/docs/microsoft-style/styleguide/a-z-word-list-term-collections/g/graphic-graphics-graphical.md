# graphic, graphics, graphical

As a noun, use _graphic_ to refer to a picture, display, chart, or other visual representation.

Use _graphics_ to refer in general to pictures, displays, charts, and other visual representations using computers. For example, _graphics software._

Most of the time, use _graphical_ as an adjective. Use _graphic_ as an adjective only to mean vivid or realistic or in the phrase _graphic arts._

**Examples**<br />To import a graphic from another file, select **Picture**.<br />Select the graphics file you want to open. <br />The image is graphic and accurate.<br />This course provides graphic design basics.<br />The graphical UI simulates a coliseum.
