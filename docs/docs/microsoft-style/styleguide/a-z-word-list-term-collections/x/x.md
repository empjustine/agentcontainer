# x

Use a lowercase _x_ in italic type as a placeholder number or variable.

Don't use _x_ to refer to a generic, unspecified number. Use _n_ instead.

Don't use _x_ in place of a multiplication sign.

**See also** [n](~/a-z-word-list-term-collections/n/n.md), [multiplication sign (×)](~/a-z-word-list-term-collections/m/multiplication-sign.md)
