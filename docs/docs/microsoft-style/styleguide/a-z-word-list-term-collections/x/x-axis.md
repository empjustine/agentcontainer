# x-axis

Lowercase. Hyphenate.

On the first mention, use _category (x) axis_ to refer to the horizontal axis in charts and graphs that shows the categories being compared. On subsequent mentions, use _x-axis._ It's OK to use _horizontal (x) axis_ in content for a general audience.

Don't use italic formatting for the _x_ in _x-axis_ unless the entire word is italic.
