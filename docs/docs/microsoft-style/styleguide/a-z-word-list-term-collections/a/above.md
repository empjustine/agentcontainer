# above

Don't use to mean _earlier_.

Don't use as an adjective preceding a noun (_the above section_) or following a noun (_the code above_). Use a hyperlink, or use _previous, preceding,_ or _earlier._

**Examples**  
Use the preceding code to display information about the database.  
See [Installation instructions](https://example.com/).  
See Installation instructions, earlier in this article.
