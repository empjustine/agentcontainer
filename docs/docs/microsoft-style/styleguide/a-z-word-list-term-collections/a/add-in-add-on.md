# add-in, add-on

Use _add-in_
to refer to software that adds functionality to a larger program,
such as the Skype Meeting Add-in for Microsoft Outlook. _Add-in_ can also refer to a driver or to a customer-written program that adds functionality to a larger program, such as a wizard.

Use _add-on_ to refer to a hardware device, such as an external drive, that's attached to the device.

In content for a general audience, use _add-in_ and _add-on_ primarily as modifiers. For example, _add-in program_ or _add-on drive_.
