# applet

Use to refer to an HTML-based program that a browser downloads temporarily to a customer's hard drive. _Applet_ is most often associated with Java.

In general, when referring to a small program, use the name of the program or the most appropriate term, such as _item, app, program, add-in,_ or _applet._

**Example**  
A Java applet in an HTML document supports animation, music, and page updates.
