# arrow

In content teaching basic skills, it's OK to use _arrow_ to identify the arrow next to a list box label. Don't use _up arrow_ or _down arrow,_ which refer to the arrow keys on the keyboard.

**Example**  
Select the **Font** arrow to display the list.
