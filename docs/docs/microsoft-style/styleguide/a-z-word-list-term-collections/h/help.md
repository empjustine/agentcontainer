# Help

Most of the time, use just _Help._ Don't use _online Help_ unless you need to describe the Help system. Capitalize when referring to a Help system within a product.

It's OK to use _definition Help, context-sensitive Help,_ and _online Help files_ to describe the Help system itself or to explain how to develop a Help system.
