# HDMI (High-Definition Multimedia Interface)

Use only as an adjective.

Use the abbreviation _HDMI_ most of the time. It’s OK to spell out in parentheses on the first mention.

Use _an_ as an article with _HDMI._

**Examples**  
This monitor requires an HDMI cable.  
Connect the HDMI cable to the HDMI port on your TV.
