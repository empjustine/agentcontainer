# hang

Don't use.

Use _stop responding_ to describe a situation in which a program encounters a problem and can’t close itself. (It's OK to mention _hang_ to support search engine optimization.)

**Example**  
If the application stops responding, or _hangs,_ you might have to restart your computer.

Use _close_ to describe the action a program takes to close itself when it has encountered a problem and can’t continue.

**Note** Sometimes
the computer itself stops responding, and sometimes a program
does. In messages, refer to the problem with precision and
specificity.

**See also** [stop, stop responding](~/a-z-word-list-term-collections/s/stop-stop-responding.md)
