# half inch

Hyphenate as an adjective. Use instead of _half an inch_ or _one-half inch_. When space is limited or the measurement needs to be specific, use _0.5 in_.

**Global tip** Be
careful when using abbreviations or acronyms that form English words.
Machine translation might incorrectly translate
the abbreviation _in._ as the word _in_.
