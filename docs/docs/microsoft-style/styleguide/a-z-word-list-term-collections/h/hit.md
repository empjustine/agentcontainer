# hit

Don't use to refer to pressing a key. Use _select_ instead.

Use _page view_ or _page request,_ not _hit,_ to refer to the number of times a complete webpage, with all its associated files, has been downloaded. It's OK to use _hits_ to
refer to the number of times a file that's part of a webpage has been
retrieved. A single page view can result in many hits.
