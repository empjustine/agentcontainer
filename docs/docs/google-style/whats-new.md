# What's new

## Page Summary

- The style guide is actively maintained and updated frequently with new terms, guidance, and best practices.
- Significant emphasis is placed on clarity, consistency, accessibility, and inclusivity in technical documentation.
- The "word list" is a core element, regularly updated with preferred and discouraged terms for writers to follow.
- Updates address a broad range of topics: code formatting, UI elements, grammar, headings, links, images, and more.
- The style guide aims to improve the overall quality and effectiveness of technical documentation for a global audience.

This page provides a summary of significant changes to the style guide.
