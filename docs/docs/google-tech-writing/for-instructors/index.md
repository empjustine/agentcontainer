# Facilitating Technical Writing Courses

## Page Summary

- This page provides resources for facilitating technical writing courses, including facilitator guides, slide decks, and student materials.
- Facilitator video guides offer in-depth explanations and support for leading Technical Writing One and Two activities.
- The resource table links to materials for Technical Writing One, Technical Writing One: Virtual Edition, Technical Writing Two, Technical Writing Two: Virtual Edition, and Tech Writing for Accessibility.
- Videos cover individual exercises within Technical Writing One and Two, offering guidance on topics such as audience, active voice, and tutorials.
- A video explaining the technical requirements for virtual editions of Technical Writing One and Two is available.
